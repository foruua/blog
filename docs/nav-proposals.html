结构不变：三项常驻 + 「页面」下拉 + 检索。四版都在现有令牌里（纸面 --bg、细界 --rule、一处金 --accent），差别在字体、结构、组件、版式各取一路。每版都放在真实页头比例里，悬停「页面」可展开下拉，悬停其它项看反馈。

方案 A · 书眉

TYPOGRAPHIC

导航收回字体本身：宋体题名、字距放宽、去图标。当前页不是换颜色，而是落一条 2.2rem 的金线 —— 就是正文里那条 --mark，位置和长度都跟着字走。检索补上「⌘K」，从一枚同重图标变成可用性入口。

  • 宋体题名
  • 去图标
  • 金线游标
  • 检索 + ⌘K

方案 B · 目录

INDEX

把导航当目录排：每项前一枚等宽序号，项与项之间用细竖线分栏，当前页的序号转金、字重升一档。语言直接沿用窄屏抽屉右端那排 01/02/03 —— 抽屉里已经有过，桌面版只是把它收小。

  • 等宽序号 01—04
  • 竖线分栏
  • 「页面」续编 05—08
  • 检索 + /

方案 C · 墨锭

COMPONENT

四项装进一只纸屉：一圈细线、一点纸底，当前项落成一枚墨锭 —— 深色胶囊、反白字。导航从此是一个有边界的物件，命中区从 24px 抬到 32px，悬停与当前都靠底色说话，不再靠图标转金。

  • 纸屉胶囊
  • 当前项＝墨锭反白
  • 保留图标
  • 检索独立圆钮

方案 D · 报头

MASTHEAD

把页头拆成两层：上层字标与检索、日期，下层一条独立目录带，四项中英双行居中。中文宋体、英文等宽小字，像杂志报头；导航有了自己的整幅界栏，中宽度下也不再和字标抢一条线。

  • 双层页头
  • 中英双行
  • 检索上移
  • 上下双界栏

四版放在一起

方案当前页怎么读密度视觉重量改动量更适合
A · 书眉宋体 + 2.2rem 金线疏轻小 · 只改 .nav现在这四项，想更像一本书
B · 目录金色序号 + 600 字重中中小 · .nav + 序号导航会变多、想强调结构
C · 墨锭墨色胶囊反白密重中 · 多一层容器可用性优先、触控与低视力
D · 报头中文转金 + 英文转墨疏中大 · 页头重排以后加日期、副题，做杂志报头

如果只选一版：A。它把导航收回字体本身，金线用的还是正文里那条 --mark，最接近站点已有的书卷气质；去图标省下的那点辨识成本，用字距和字重补得回来。

C 的可用性最强，但会给站点引入一层目前没有的容器语言，建议只在「当前项必须一眼可见」成为硬需求时采用。B 适合导航长到六项以上；D 适合把页头当报头经营、愿意为它让出一行首屏的时候。

四版都不动窄屏抽屉与无 JS 兜底；检索仍提交到 /search，「页面」仍是 details，悬停展开只是桌面增强。
